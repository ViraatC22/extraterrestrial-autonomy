# Swarm extension paper (superseded as the primary study)

This directory holds the completed write-up and generated assets for the
original multi-robot study: *Decentralized versus Learned Swarm Coordination
for Communication-Constrained Lunar Exploration*.

It is preserved because the work and its results are real. It is kept separate
from the EXONAUT paper so that swarm-era figures and tables can never be
mistaken for results of the single-robot adaptive-autonomy study, which uses a
different simulator, different dependent variables, and a different seed
protocol.

The code behind this paper now lives in `src/exonaut/multiagent/`.
