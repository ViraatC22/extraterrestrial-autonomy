# Swarm-extension results (not EXONAUT)

`main_sweep.csv` is the result set for the original multi-robot coverage study
(`src/exonaut/multiagent/`). Its dependent variables are coverage-based and its
seeds come from a different protocol entirely.

It is kept apart from the EXONAUT mission results so the two can never be
pooled or confused. The paper for this study is in `paper/swarm_extension/`.
